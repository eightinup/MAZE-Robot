# MAZE Robot — Pixel Arcade

Коллекция из трёх браузерных мини-игр на C++ / SDL2, собираемых в WebAssembly через Emscripten.

## Цель переработки

Сделать проект цельной Pixel Art-аркадой, удобной на компьютерах и смартфонах:
- единое главное меню и визуальный язык;
- понятное управление с клавиатуры и сенсорного экрана;
- полноценные игровые циклы, уровни, победа/поражение и перезапуск;
- сохранение прогресса и настройки;
- адаптивный игровой экран и доступные подсказки.

## Игры

- **Maze** — прохождение лабиринтов.
- **Tanks** — арена с препятствиями, столкновениями и противниками.
- **Miner** — пошаговая головоломка с программированием действий.

## Локальная сборка

Требуется Emscripten SDK с поддержкой SDL2:

```sh
mkdir -p public
emcc main.cpp -s USE_SDL=2 -s ALLOW_MEMORY_GROWTH=1 \\
  --shell-file shell.html -o public/index.html
```

Откройте public/index.html через локальный HTTP-сервер, а не через file://.

## Публикация

GitHub Actions собирает WebAssembly и публикует GitHub Pages при push в main.
Рабочая переработка ведётся в ветке feature/pixel-art-rebuild; она не заменяет
публичную версию, пока изменения не проверены и не объединены.
