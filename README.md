# MAZE Robot — Pixel Arcade

**MAZE Robot** — небольшая пиксельная аркада на C++ / SDL2 с браузерной сборкой WebAssembly через Emscripten.

Проект развивается в отдельной ветке `feature/pixel-art-rebuild`. Основная ветка `main` остаётся нетронутой до завершения проверки.

## Игровые режимы

- **Maze** — пройди три лабиринта 5×5, следи за количеством шагов и найди выход. Кнопка RST сбрасывает текущий уровень.
- **Tanks** — пройди три волны противников на разных аренах. Используй укрытия, следи за здоровьем и адаптируйся к усилению врагов.
- **Miner** — составь последовательность команд, чтобы добраться до алмаза.

## Управление

| Режим | Компьютер | Смартфон / планшет |
|---|---|---|
| Меню | Нажатие мышью | Касание кнопки |
| Maze | WASD или стрелки | Экранный D-pad; RST — сброс уровня |
| Tanks | WASD — движение, Space — выстрел; три волны на разных аренах | Экранный D-pad и FIRE |
| Miner | Экранные кнопки команд и PLAY | Касание экранных кнопок |

Внутри игры:
- **Escape** — пауза / продолжение.
- **←** — возврат в меню.
- **II** — открыть паузу.
- В Miner кнопка **RESET** перезапускает уровень и очищает программу; после победы можно нажать **PLAY AGAIN**.

## Локальная сборка

Требуется установленный Emscripten SDK с поддержкой SDL2:

```sh
mkdir -p public
emcc main.cpp -s USE_SDL=2 -s ALLOW_MEMORY_GROWTH=1 \
  --shell-file shell.html -o public/index.html
```

Запускайте результат через локальный HTTP-сервер, а не через `file://`. Например:

```sh
cd public
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.
